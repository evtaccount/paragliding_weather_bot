# DECISIONS — защита от абьюза API

- **Доступ по whitelist, не публичный бот.** `ALLOWED_USER_IDS` в `.env`; пустая
  переменная = открытый режим с WARNING в логе (не ломает существующий деплой).
  Чужому — отказ с его Telegram ID (не чаще раза в минуту, чтобы бот не спамил в ответ).
- **Защита квот: кэш + кулдаун; дневной бюджет Gemini решили не делать** —
  при whitelist это избыточно.
- **Кэш хранит PNG как байты в памяти**, а не файлы: temp-dir удаляется сразу в
  `forecast.py`, отправка через `BufferedInputFile`. Объём мал (несколько сотен КБ).
- **Кулдаун только на команды прогноза** (флаг aiogram `forecast`): `/help`,
  `/sites`, `/start` не ограничиваются — они не тратят внешние квоты.
- **Сырой текст исключений в ответах и `SystemExit` из `engine.find_site`** —
  замечены в ревью, осознанно не трогаем без отдельной задачи.
